# Definition of Done

Una tarea se considera terminada cuando:

- Fue trabajada en una rama diferente a main.
- Tiene un Pull Request asociado.
- El Pull Request está vinculado al issue.
- El pipeline CI pasó correctamente.
- Se ejecutaron las pruebas correspondientes.
- El código fue revisado por al menos un compañero.
- La documentación fue actualizada si aplica.
- El issue fue cerrado correctamente.
