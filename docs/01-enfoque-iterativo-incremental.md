# Enfoque iterativo e incremental

El proyecto YO-SOY-CRUD se trabajará bajo un enfoque iterativo e incremental. No se adopta Scrum ni Kanban como metodología rígida, ya que el objetivo del taller es industrializar un monorepo existente mediante mejoras progresivas.

Cada incremento entrega una mejora verificable: gestión de tickets, documentación, pipeline CI, Pull Requests, revisión de código, pruebas automatizadas y generación de releases.

El tablero de GitHub Project se usa como herramienta visual de seguimiento para controlar el avance de los tickets desde Backlog hasta Done.
