# Política de Pull Requests

Todo cambio debe integrarse mediante Pull Request.

## Reglas

- El PR debe estar vinculado a un issue.
- El PR debe indicar el módulo afectado.
- El PR debe tener descripción clara.
- El pipeline CI debe pasar correctamente.
- Al menos un compañero debe revisar el PR.
- No se debe hacer merge si fallan las pruebas.
