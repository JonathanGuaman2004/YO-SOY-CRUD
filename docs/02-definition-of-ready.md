# Definition of Ready

Un ticket está listo para iniciar cuando:

- Tiene título claro.
- Tiene descripción del problema o necesidad.
- Tiene tipo definido: Feature, Bug, Technical Debt o Task.
- Tiene módulo asociado del monorepo.
- Tiene criterios de aceptación verificables.
- Tiene prioridad definida.
- Tiene responsable asignado.
- Puede trabajarse en una rama independiente.
